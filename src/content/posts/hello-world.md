Welcome! This is the first post in the _misc_ section, the place for notes,
half-formed ideas and anything that isn't a project.

## How the site is built

The site is plain static HTML, generated by [Astro](https://astro.build) and
served by Cloudflare. There's no tracking and almost no JavaScript. Pages are
fast because there's very little to load.

Every project and post is a single Markdown file. Adding one looks like this:

```md
---
title: My new post
description: One sentence that shows up in lists and search results.
date: 2026-10-01
---

The post itself, written in **Markdown**.
```

## Things that run in the browser

Small interactive demos live alongside the site as plain HTML, JavaScript,
canvas or WebAssembly. Each one gets its own URL under `/demos/`, and project
pages can embed them. Here's the starter demo (move your pointer or finger
over it):

<iframe src="/demos/example/" title="Starter demo: a drifting particle field" loading="lazy" height="360"></iframe>
